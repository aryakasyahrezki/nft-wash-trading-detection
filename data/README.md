# Data

## Download
1. Download the Simiotic Ethereum NFT dataset from:  
   https://www.kaggle.com/datasets/simiotic/ethereum-nfts

2. After running the preprocessing notebooks, the processed graph 
   dataset will be saved as `nft_graph_dataset.npz`.

## Note
Raw and processed data files are not included in this repository 
due to size constraints and licensing. Run notebooks 01-04 in order 
to reproduce the processed dataset from the raw source.
